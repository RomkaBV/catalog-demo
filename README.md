# BU Catalog Secure V6

У цій версії виправлена небезпечна логіка видалення.

## Що змінилось
- У стандартному редагуванні більше немає великої кнопки «Видалити позицію» поруч із «Зберегти».
- Для кожного фото є окрема чітка кнопка «Видалити фото» / «Скасувати».
- Видалення позиції заховане у секції «Небезпечні дії».
- Для видалення позиції потрібен окремий `DELETE_KEY` + повторне введення артикулу.
- Видалена позиція не стирається назавжди: вона переноситься в окремий аркуш `Archive`.
- В адмін-режимі є кнопка «Відновити», яка повертає позицію з `Archive` за артикулом.

## Оновлення Google Apps Script
1. Замініть поточний `Code.gs` в Apps Script на `Code_V6.gs`.
2. У `CONFIG` задайте власний складний `DELETE_KEY` замість `CHANGE_ME_DELETE_PASSWORD`.
3. `ADMIN_KEY` залиште вашим поточним ключем для редагування/додавання фото.
4. Збережіть код.
5. Apps Script → Ввести в дію → Керувати введеннями в дію → олівець → Нова версія → Ввести в дію.
6. `/exec` URL не змінюється.

## Оновлення GitHub Pages
Замініть лише `index.html` на файл із цієї папки.

## Права
- Людям, які додають фото, давайте лише звичайний ключ адміністратора/редактора.
- `DELETE_KEY` залишайте тільки у себе.
- Без `DELETE_KEY` видалити позицію неможливо.

## Відновлення
Після видалення позиція потрапляє в аркуш `Archive` Google Sheet. В адмін-режимі натисніть «↩ Відновити», введіть артикул та `DELETE_KEY`.

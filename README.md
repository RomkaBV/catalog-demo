# Каталог майна — GitHub Pages

Ця версія зберігає попередній дизайн демо-сайту, але `app.js` вже містить усі 252 позиції з Excel.

## Що перенесено з Excel
- усі 17 колонок аркуша `Звіт OLX`;
- усі 16 колонок аркуша `Вихідні дані`;
- 345 назв файлів фотографій, прив'язаних до відповідних інвентарних номерів;
- ціни, посилання, кількості, примітки, статуси та коментарі.

Відкрий `Детальніше` у картці позиції — внизу є блок `ВСЯ ІНФОРМАЦІЯ З EXCEL`.

## Оновлення GitHub
Просто завантаж у корінь репозиторію ці 4 файли поверх старих:
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

Окремі файли даних не потрібні.

Фотографії фізично не містяться в Excel. Якщо пізніше завантажити JPG у папку `images/` з тими самими назвами, каталог почне показувати їх автоматично.


## Google Drive фото

У цій версії з Excel підключено **345** Google Drive-посилань до **125** позицій. Перше фото використовується як прев'ю картки, усі фото доступні в галереї позиції. Для відображення прев'ю файл у Google Drive має бути доступний користувачу сайту.

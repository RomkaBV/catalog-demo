# БУ Каталог — виправлена версія для GitHub Pages

Ця збірка зроблена спеціально так, щоб не ламались CSS/JS через неправильні шляхи.

## Для першого запуску
1. У репозиторії GitHub видаліть старий `index.html` (або замініть його).
2. Завантажте **цей `index.html` у корінь репозиторію**.
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Зачекайте 1–3 хвилини і оновіть сторінку через Ctrl+F5.

Для публічного перегляду каталогу достатньо одного `index.html`.
CSS, JavaScript, дані каталогу та фонове фото вже вбудовані всередину.

## Адмінка / завантаження фото у Google Drive
Для цього додатково потрібен Google Apps Script. Файли лежать у папці `apps-script`.
Після розгортання Apps Script вставте його `/exec` URL у блоці `window.APP_CONFIG` всередині `index.html` (пошук по `API_URL`).

Фото товарів залишаються у Google Drive і показуються прямо на сайті.


## Фото з телефона
У режимі адміністратора кнопка **«Зробити фото»** відкриває задню камеру телефона. Кожен зроблений кадр додається до попереднього перегляду. Після натискання **«Зберегти»** фото стискаються у браузері, завантажуються в Google Drive через Apps Script і прив’язуються до товару. Кнопка **«Обрати з телефону»** дозволяє вибрати кілька фото з галереї.

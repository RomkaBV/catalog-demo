# Каталог V6 — місто та адреса

На картках і в деталях показується локація: м. Чернігів, вул. Інструментальна, 34а.
Це значення за замовчуванням для позицій без окремо заданої локації.
У редакторі є окремі поля «Місто» і «Адреса». Над картками додано фільтр «Усі локації».
Пошук також знаходить місто та адресу.

## Встановлення
1. Замініть index.html у вашому репозиторії GitHub на файл із цього архіву.
2. У чинному проєкті Google Apps Script замініть Code.gs вмістом Code_Location.gs.
3. Перенесіть із вашого чинного Code.gs значення ADMIN_KEY та DELETE_KEY; перевірте SPREADSHEET_ID і DRIVE_FOLDER_ID.
4. Один раз запустіть prepareLocation(). Вона заповнює лише порожні поля міста й адреси в Catalog.
5. Ввести в дію → Керувати введеннями в дію → Олівець → Нова версія → Ввести в дію.
   Оновлюйте чинне введення в дію, щоб адреса /exec залишилася тією самою.
6. Оновіть сторінку сайту та перевірте картку, фільтр і збереження нової адреси.

Catalog: A:G зберігають старий порядок; City додається у H, Address — у I.
Archive: DeletedAt лишається у H; City — у I, Address — у J.
Існуючі дані обладнання та фотографії не переносяться й не видаляються.
Логіни, ролі та журнал користувачів у це оновлення не додано.
Зміни підготовлено у файлах; чинний сайт і Google Apps Script автоматично не оновлено.

# Каталог майна — GitHub Pages

Ця версія вже містить дані з Excel-файлу **Звіт OLX Чернігів**.

- Позицій: 252
- Посилань на фото/назв фото в Excel: 345
- Самі фото в Excel не були вбудовані, тому для їх показу потрібно додати JPG-файли в папку `images/` з тими самими назвами.
- Оригінальний Excel лежить у `data/catalog.xlsx` і доступний із кнопки **Excel** на сайті.

## Як оновити GitHub

Завантаж у корінь репозиторію:
- `index.html`
- `styles.css`
- `app.js`
- `catalog-data.js`
- папку `data`
- папку `images` (поки може бути порожня)

Якщо GitHub запитає про заміну файлів, підтверди заміну `index.html`, `styles.css`, `app.js`.

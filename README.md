# Каталог майна — GitHub Pages Demo

Статичний демо-сайт каталогу, який можна безкоштовно опублікувати через GitHub Pages.

## Можливості
- каталог позицій;
- пошук і фільтри;
- форма додавання позиції;
- кілька фотографій;
- статуси: В продажу / Заброньовано / Продано;
- збереження даних у localStorage браузера;
- адаптивний дизайн.

## Важливо
Це фронтенд-демо без бекенду. Дані, які додаються через форму, зберігаються тільки у конкретному браузері/на конкретному пристрої. Інший користувач їх не побачить.

Для повноцінного сайту з постійними товарами, фотографіями, користувачами та доступом з різних пристроїв варто підключити Supabase або Firebase.

## Як опублікувати на GitHub Pages
1. Створи новий репозиторій на GitHub, наприклад `catalog-demo`.
2. Завантаж `index.html`, `styles.css`, `app.js` у корінь репозиторію.
3. Відкрий Settings → Pages.
4. У Source вибери Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Збережи. Через короткий час GitHub покаже адресу сайту.

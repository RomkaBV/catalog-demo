ВИПРАВЛЕННЯ ФОТО / МОБІЛЬНОГО ЗАВАНТАЖЕННЯ

1. GitHub Pages
   Замініть index.html на файл index.html з цієї папки.

2. Google Apps Script
   Замініть поточний Код.gs на Code_V2.gs.
   Збережіть проєкт.

3. Відновлення старих фото
   Додайте в Apps Script новий файл RepairPhotos.gs.
   Вставте в нього вміст RepairPhotos.gs з цієї папки.
   Запустіть repairSeedPhotos() ОДИН РАЗ.
   Функція лише додає відсутні початкові фото з Excel і не видаляє нові фото.

4. Оновіть розгортання Apps Script
   Ввести в дію -> Керувати введеннями в дію -> олівець -> Нова версія -> Ввести в дію.
   Якщо редагуєте існуюче розгортання, /exec URL залишається тим самим.

5. Оновіть index.html на GitHub і на телефоні перезавантажте сторінку.

Що виправлено:
- нове фото більше не замінює старі;
- видалення фото відбувається лише коли воно явно зняте галочкою;
- мобільні фото стискаються до 1280 px / JPEG 74% перед відправкою;
- після натискання «Зберегти» вікно закривається автоматично, а статус показується повідомленням унизу;
- додано примусове оновлення даних без кешу;
- додано повторні спроби завантаження Google Drive-фото на мобільному.

Після перевірки роботи рекомендується змінити ADMIN_KEY на новий довший ключ і знову оновити deployment.

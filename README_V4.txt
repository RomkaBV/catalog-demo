BU Catalog — Browser V4

Що виправлено:
- Google Drive фото спочатку відкриваються через googleusercontent (краще для мобільних та вбудованих браузерів).
- На телефоні перша сторінка фото завантажується eager, без проблем браузерного lazy-loading.
- Якщо всі прямі Google URL не спрацювали, сайт робить захищений fallback через Apps Script і показує фото як data URL.
- Fallback дозволяє читати ТІЛЬКИ File ID, які вже записані у PhotosJSON каталогу.
- При поверненні у вкладку на телефоні каталог повторно підтягується з Google Sheet.
- Стиснення фото з камери швидше та стійкіше для iOS/Android/in-app browsers.
